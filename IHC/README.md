**Como era a Interação Humano Computador + - 70? CLI**

O **command line interface** é um sistema que a interação com computador é feita via linha de comando,ele possui alta desempenho, porém pouca usuabilidade, por exemplo, o terminal cmd do windows.

**E dos + - 80 até 2007? GUI**

A **graphical user interface** é um sistema que a interação com o computador é feita via uma tela, por exemplo, o windows que é possível  ultilizar o sistema através de botões.
 
**E de 2007 até agora? NUI**
O **natural user interface** é um sistema que ultiliza comandos através de ações comuns do dia, por exemplo, o dedo em uma botão para selecionar ele.


**Qual o futuro da IHC???**
O futuro da **interação humano e computador** é através das IAs conseguir realizar tarefas complexas com poucos passos, por exemplo, fazer a instalação de um programa apenas pedindo para a IA deixando de responsabilidade dela a procura do programa na web e seu processo de instalação.
